How findings are made +

EXACT_DUPLICATE
Question text occurs verbatim in a training sample after Unicode case folding and whitespace collapsing, with word boundaries.

PARAPHRASE / ANSWER_LEAKAGE
Validators independently classify the same locked pairs. They compare compact labels, never generated explanations.

NO_OVERLAP_FOUND / INCONCLUSIVE
No overlap means none found in this batch. Missing context or unusable model output remains uncertain. Consensus failure is a transaction failure, not a finding.
